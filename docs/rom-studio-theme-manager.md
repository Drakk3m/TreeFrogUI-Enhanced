# ROM Studio Theme Manager integration

Use tools/theme-manager/catalog.json as the tooling contract. It distinguishes editable pack resources and protected roles. Catalog version and manifest version evolve independently. FrogUI only reads theme.ini and native artwork from the selected pack. Run python3 tools/theme-manager/validate-catalog.py from the FrogUI checkout to verify the identifier patterns, opacity ranges and image limits against runtime source.

1. Inspect the selected pack and join resource IDs to the catalog. Substitute lowercase ASCII keys from the platform ROM folder, existing app_defs ID or Settings category ID. Keep unknown entries when editing an existing pack. They can be shown as unsupported without giving them an editable device preview.
2. Preview with the role's operation. An icon is aspect-fit using its alpha channel. A background uses native wallpaper fit. Recommended dimensions are export targets. Image limits, header format and size are validation constraints. Use 8-bit noninterlaced PNG for alpha, or JPEG/BMP for opaque art. A desktop preview approximates the device's RGB565 result.
3. Reject duplicate editable mappings, unsafe paths, oversized files, unsupported input, invalid dimensions and out-of-range presentation values. Require a relative pack-local regular file; prohibit path traversal, symlinks and absolute paths. Fully decode images during Studio validation. A valid header alone cannot establish valid pixel data. The catalog's protected roles expose no RAW conversion rules or asset relocation.
4. Stage and validate a complete named package, then publish it under frogui/theme-packs/<name>. Keep conventional native background names for Classic fallback. Write the manifest beside them. Keep the existing pack until the new selection has been tested. Select the pack via Background Theme Pack. Switch packs or restart after replacing files. The existing font selector continues to work independently.
5. Restore a resource by deleting the corresponding mapping in the staged package. Restore the frontend appearance by selecting Default or the prior pack. A test-card rollback may restore the settings backup. Do not export game-specific covers, runtime captures, saves, RA progress or private RA media with themes.

Run python3 tools/theme-manager/make-reference.py OUTPUT_DIR to generate two native packages. The reference has procedural sample artwork. The minimal fixture omits every optional mapping. The packages demonstrate the implemented resource contract without requiring ROM Studio to change its data formats.
