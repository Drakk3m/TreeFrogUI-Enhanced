| ra_lab.c rcheevos calls | Parser activation, address validation, per-frame evaluation, reset and destruction. Six runtime IDs and a fixed event queue. | Reuse rcheevos API and event boundary. Allocate runtime IDs deterministically per ID table. |

Measure FAT path and write cost separately. |
| core.c deserialize/reset, main.c rewind, menu.c reset | Clears transient state after successful state load/reset and rewind discontinuities. Durable bits live outside emulator state. | Preserve local soft-mode semantics. Quick Resume follows state loading. |
| plat_sdl.c composition, core.c audio callbacks | Existing owned RGB565 compositor draws a top-right timed badge/title notification. Mixes a generated chime into callback audio. | FrogUI ra_lab_gallery.h and frogui_libretro.c | SD reads validate exact local fixture bytes and supported ROM contents at Details; public reader remains separate. | FrogUI ra_game.c and ra_profile.c | rom_identity.json is indexed by relative path; public metadata view matches exact platform, positive console/game IDs, 32-hex RA hash, metadata method and size/mtime tolerance. gamepack.json requires schema_version 1 and matching console/game/hash, unique positive achievement IDs and nonempty titles.
